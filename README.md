# Puzzle Play

Sudoku, Word Search and Jigsaw in one ad-free app. It runs in any browser and installs to your phone's home screen as a Progressive Web App (PWA), opening full-screen and working offline.

This repo merges the old `puzzle_play-web` (Vite + React) and `puzzle_play-mobile` (Expo) projects. The web app was already a superset of the mobile one, so it became the base. Installing the PWA replaces the need for an App Store / TestFlight build.

## Why I built this

I love puzzles. Sudoku, Word Search and Jigsaw have always been my go-to for a mental workout, but every app I found was riddled with ads that broke my flow. So I built my own: clean, fast and completely ad-free.

## Games

### 🔢 Sudoku
Six levels, from a 4×4 Mini to a 9×9 Expert.
- Unlimited puzzles per level
- Undo, Erase, Notes mode and 3 Hints per game
- Green sweep when you complete a row, column or the whole board
- Best time per level, saved on the device
- No game-over: mistakes only appear in the final summary

### 🔍 Word Search
Five levels, from Mini (8×8) to Expert (16×16).
- Generated grids with themed word lists
- More directions unlock as difficulty rises
- Timer and found-word counter

### 🧩 Jigsaw
Nine levels, from Tiny (4 pieces) to Ultimate (225 pieces).
- Photos from Picsum, cached after first load so finished puzzles replay offline
- Drag pieces up from the tray (or tap a piece, then a slot); correct pieces join seamlessly
- Preview the full image any time

## Tech stack

React 18 · TypeScript · Vite 5 · Zustand · React Router 6 · Motion · vite-plugin-pwa · Firebase Hosting

## Design

A printed-puzzle-book direction, informed by NYT Games, Good Sudoku and Puzzmo: warm paper (`#F5F1E8`), ink-black type and 1.5px rules, and one flat colour per game: cobalt Sudoku, marigold Word Search, tomato Jigsaw. Headlines are set in Fraunces and interface text and all numerals in Figtree. Buttons press down onto an offset ink shadow. Tokens live in `src/design/tokens.ts` (mirrored as CSS variables in `src/index.css`). Shared screens (`TopBar`, `LevelScreen`, `CompletionSheet`, `GameMark`, `Icon`) are in `src/components/ui/`.

## Getting started

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # outputs dist/ with manifest + service worker
npm run preview    # test the production build (service worker included)
```

## How the app install works

| Piece | Where |
|---|---|
| Web app manifest (`display: standalone`, icons) | generated from `vite.config.ts` |
| iPhone tags (`apple-touch-icon`, `apple-mobile-web-app-*`, `viewport-fit=cover`) | `index.html` |
| Service worker (precaches the app, SPA fallback, caches jigsaw photos and fonts) | generated by `vite-plugin-pwa` (`generateSW`) |
| HTTPS + `no-cache` on `sw.js` / `index.html` | `firebase.json` |
| Safe-area padding, `100dvh`, no rubber-band bounce or long-press callouts | page roots + `src/index.css` |

Icons live in `public/`. `icon.svg` is the source. The PNGs (192, 512, a maskable 512 and a 180 `apple-touch-icon` with a solid background) are rendered from it.

## Deploy

Live at **https://puzzleplay-app.web.app** (Firebase project `puzzleplay-app`).

```bash
npm run build
firebase deploy --only hosting
```

## Install on your phone

- **iPhone:** open the site in Safari → Share → **Add to Home Screen**, and keep **Open as Web App** on.
- **Android:** Chrome offers **Install app**, or use ⋮ → Add to Home screen.

If you change the manifest or icons later, delete the home-screen icon and add it again. iOS remembers how the icon was first added.

## Replacing Jigsaw images

Edit `src/utils/jigsawData.ts`.
